# NER sidecar (slovnet + navec + razdel)

Локальный Python-процесс для распознавания именованных сущностей (PER/LOC/ORG)
в свободном русском тексте. Использует низкоуровневые библиотеки Natasha:
[slovnet](https://github.com/natasha/slovnet) (NER-модель),
[navec](https://github.com/natasha/navec) (embeddings),
[razdel](https://github.com/natasha/razdel) (сегментация).

Модель и embeddings загружаются **один раз при старте** процесса. Внешние API
не используются.

## Требования

- Python 3.12+ (установлен в `C:\Users\user\.python-ner\python.exe` в этой среде).
- Зависимости: `pip install -r ner/requirements.txt`.
- Модели (скачиваются один раз в `ner/models/`):
  - `navec_news_v1_1B_250K_300d_100q.tar` (25 MB)
  - `slovnet_ner_news_v1.tar` (2 MB)

## Запуск

```bash
python ner/server.py
```

Переменные окружения:
- `NER_HOST` — адрес прослушивания (по умолчанию `127.0.0.1`).
- `NER_PORT` — порт (по умолчанию `8090`).

## Протокол

`POST /ner` — распознавание сущностей.

Запрос:
```json
{ "text": "Президент Франции Эмманюэль Макрон встретился с Ангелой Меркель." }
```

Ответ:
```json
{
  "spans": [
    { "start": 19, "end": 33, "type": "LOC", "text": "Франции" },
    { "start": 34, "end": 65, "type": "PER", "text": "Эмманюэль Макрон" }
  ]
}
```

`start`/`end` — **байтовые смещения в UTF-8** исходной строки (start
включительно, end исключительно), так что `text[start:end]` в Go возвращает
ровно фрагмент.

`GET /healthz` — проверка живости.

## Важно

Результаты NER — это **сырые кандидаты** с метками PER/LOC/ORG. Они НЕ
являются готовыми типами PII (`pii.Type`). Решение о том, какой тип присвоить
(или отбросить) принимает следующий слой по контексту. Поэтому результаты NER
не подключаются напрямую в общий `detection.Detector`.

## Производительность (замерено, AMD Ryzen 7 7800X3D)

- Warm latency одного запроса: ~8–9 ms.
- Параллельность не даёт прироста: sidecar обрабатывает запросы
  последовательно (модель NER не потокобезопасна). Для масштабирования нужны
  несколько sidecar-процессов или batch (следующие шаги).
